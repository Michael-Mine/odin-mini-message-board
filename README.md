# odin-mini-message-board

Odin - Mini Message Board

A mini message board app from The Odin Project.

By building from scratch, this will help solidify my recent learning of Node, Express, ejs for views, the Model View Controller (MVC) design pattern, forms and data handling using express-validator and PostgreSQL for the database.

The app is hosted on railway.

Live Link: https://mrmine-mini-message-board.up.railway.app/
